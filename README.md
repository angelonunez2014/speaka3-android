# SpeakA3 for Android

The Android app for **[SpeakA3](https://speaka3.devruki.com)** - private family trees, built together.

This repository only hosts the app's downloads. (SpeakA3 itself is at https://speaka3.devruki.com.)

## Download

**[⬇ Download the latest SpeakA3.apk](https://github.com/angelonunez2014/speaka3-android/releases/latest/download/SpeakA3.apk)**

All versions: [Releases](https://github.com/angelonunez2014/speaka3-android/releases)

## Install (it isn't on the Play Store yet)

1. On your Android phone (Android 8.0 or newer), open the download link above.
2. When it finishes, tap the downloaded **SpeakA3.apk**.
3. If Android asks, allow your browser to **install unknown apps** (Settings → *Install unknown apps* → your browser → *Allow*).
4. Tap **Install**, then **Open**. Sign in with the same account you use on the website.

To update, download the latest APK the same way - it installs over the old one and keeps you signed in.

## Is it safe?

The app just opens https://speaka3.devruki.com full-screen in your phone's Chrome engine (a "Trusted Web Activity"). It asks for no special permissions besides internet access. Every release lists the file's SHA-256 checksum so you can check the download.
